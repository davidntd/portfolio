
# Portfolio

A retro, pixel-styled personal portfolio page built with [Next.js](https://nextjs.org).

🔗 Live: [davidntd-portfolio.vercel.app](https://davidntd-portfolio.vercel.app/)

## Overview

Welcome to my personal portfolio site. The page opens with a terminal-style boot screen ("PRESS ENTER TO START") before revealing the main content, which is organized into the sections below. Please check out the page as you like.

## Sections

**Introduction** — Name, tagline, signature graphic, and a downloadable resume/CV.

**Profile** — Photo, name, role, availability status, core strengths, languages spoken, and an "About Me" bio.

**Foundations** — Education history (school, program, dates, status, GPA, relevant coursework) and a list of awards and certifications.

**Career Log** — Work experience and activities, each showing a title, organization, location, dates, and bullet-point highlights.

**Tech Stack** — An icon grid of languages, frameworks, and tools, grouped by category, each with a proficiency level (Basic / Intermediate / Proficient) shown on tap or hover.

**Projects** — A sortable grid (Best / Recent Updates / Newest / Oldest) of projects pulled from GitHub repositories. Each card shows the project's tech icons, a description, a GitHub link, a live-demo button when available, and a Media button when the repo has a media gallery.

**Contact** — Phone, email, LinkedIn, and GitHub links, plus a contact form (name, email, message).
